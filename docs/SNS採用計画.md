# SNS 採用計画（Instagram・TikTok・YouTube Shorts）

最終更新: 2026-10-21

## 1. ルール（必ず守る）
- **事実だけを使う**: 採用サイト・採用ネタ帳（claude-vault `Projects/newvalley-sns-morning/採用ネタ帳.md`）に書いてある言葉・数字と、本人が話した内容だけ。給与・勤務時間などの未確定の条件は書かない。
- **同意**: 職員が映る場合は本人の同意（投稿先・期間）を事前にとる。利用者・子ども・保護者は**顔を出さない**（モザイク・後ろ姿・手元のみ）。書類・タイムカード・車のナンバーは映さない。
- **公開は人が確認してから**: 下書き → 採用担当が確認 → 社長が確認 → 投稿。自動投稿はしない。
- 体裁は過去の採用動画と同じ: テロップはゴシック体（太字）＋黒い半透明の枠、最後は会社ロゴ（claude-vault `Patterns/採用ショート動画.md`）。
- 投稿の最後に必ず導線: 「応募・相談は公式LINEから」＋プロフィールのリンク。

## 2. 導線
```
投稿（リール／ショート） → プロフィール → リンク（採用サイト /careers/ ・公式LINE）
                                        → 応募経路「Instagram」「TikTok」として記録
```
- 応募時に「何を見て応募したか」を聞き、応募経路に記録する（SNS の効果を測るため）。

## 3. 投稿の柱（事業別）

| 柱 | 訪問介護 | 放課後等デイ | グループホーム |
|---|---|---|---|
| 仕事内容紹介 | 直行直帰の1日（移動・待機も勤務時間） | 送迎〜活動〜お迎えの流れ（子どもは顔なし） | 開設準備の様子（開設日確定後） |
| 職員インタビュー | 施設から転職した理由・変わったこと | 子どもの成長を一緒に喜べるチーム | 立ち上げメンバーの声（採用後） |
| 職場紹介 | 町田の事務所・社用車 | マーチ（運動療育）・びよんど（学習・就労支援） | 建物・部屋（開設後） |
| 制度 | 短時間社員制度・休日の研修にバイト代 | 平日12時〜18時・残業なし（パート） | 夜勤の働き方（条件確定後） |
| 採用担当メッセージ | 「話だけ聞きたい」もLINEで歓迎 | 同左 | 同左 |

## 4. 投稿スケジュール（案）
頻度: Instagram リール 週2本（火・金）＋ストーリーズで求人告知週1回。TikTok・YouTube Shorts は開設したら同じ動画を転用。

| 期間 | テーマ | 本数 |
|---|---|---|
| 11/02〜11/08 | 求人公開のお知らせ（職種一覧）／採用担当メッセージ | 2 |
| 11/09〜11/29 | 訪問介護の1日・短時間社員制度・放デイの1日・職員インタビュー | 6 |
| 11/30〜12/20 | 応募が少ない職種を重点的に（週次レポートで決める） | 6 |
| 12/21〜01/03 | 年末年始の応募受付案内（返信の目安日） | 1〜2 |
| 01/04〜01/31 | 不足職種の集中投稿・グループホーム（開設日確定後） | 8 |
| 02/01〜02/28 | 入社した人の声（同意のうえ）・最終募集 | 4〜6 |

## 5. 動画台本（たたき台）

### 台本1: 訪問介護「移動の時間も、勤務時間です。」（30秒）
| 秒 | 画面 | テロップ |
|---|---|---|
| 0-3 | 社用車に乗り込むスタッフ（後ろ姿） | 訪問介護って、移動の時間はどうなるの？ |
| 3-10 | 運転・駐車の様子（ナンバーは映さない） | NewValley では　移動・待機の時間も勤務時間 |
| 10-18 | 自宅から直接向かう様子 | 事務所に寄らない　直行直帰 |
| 18-25 | スタッフの笑顔（同意済み） | 先輩との同行は約3ヶ月。1年間、教育担当がつきます |
| 25-30 | 会社ロゴ | 話だけ聞きたい、も大歓迎　公式LINEから |

### 台本2: 短時間社員制度（20秒）
| 秒 | テロップ |
|---|---|
| 0-4 | 子育て中だから、パートしかない？ |
| 4-12 | 勤務時間は短くても「社員」で働ける　短時間社員制度（週32時間／週28時間） |
| 12-16 | 社会保険にも加入　正社員への移行もできます |
| 16-20 | 詳しくは公式LINEで（ロゴ） |

### 台本3: 放課後等デイ パートの1日（30秒）
| 秒 | 画面（子どもは顔を出さない） | テロップ |
|---|---|---|
| 0-3 | 事業所の外観 | 放課後等デイサービスのパート、こんな1日です |
| 3-8 | 準備の様子 | 12:00 出勤 |
| 8-15 | 送迎車（ナンバーなし） | 学校へお迎え（普通免許が必要です） |
| 15-24 | 活動の手元・道具 | マーチは運動、びよんどは学習・就労支援がメイン |
| 24-30 | ロゴ | 18:00 退勤・残業なし　平日のみもOK |

### 台本4: 採用担当メッセージ（15〜30秒・本人が話す）
- 「NewValley 採用担当の〇〇です」→「いま訪問介護・放課後等デイサービスでスタッフを募集しています」→「いきなり応募じゃなくて、話だけ聞きたいでも大丈夫です」→「公式LINEから気軽に連絡ください」
- 台本どおりでなく、本人の言葉で話してもらう（言っていないことをテロップで足さない）。

## 6. 投稿文のひな形（Instagram）
```
【募集】訪問介護スタッフ（町田・大和・相模原・海老名エリア）

✔ 直行直帰
✔ 移動・待機の時間も勤務時間
✔ 先輩との同行約3ヶ月・1年間教育担当がつきます

「話だけ聞きたい」も大歓迎です。
応募・相談はプロフィールの公式LINEから📩

#訪問介護 #介護求人 #町田市 #大和市 #障がい福祉 #ニューバリー
```
（給与などの条件は、求人が確定・公開されてから求人の内容と同じものを書く）
