# 求人条件の確認事項リスト（事業責任者・社長 確認用）

`python3 -m recruit checklist` で求人マスタ（data/master/jobs.json）から自動作成。
確認できたら jobs.json の該当項目を `["確定", "内容", "確認者・日付"]` に書き換える。

凡例: **要確認**＝情報なし／**HP記載**＝自社採用サイトに記載あり（今回の求人に使ってよいか・最新かを確認）／**構想**＝掲載禁止

## 採用サイト（newvalleyhp.com）で表記が食い違っている点

求人と採用サイトの内容がずれると応募後の辞退につながるため、どちらが正しいか決めて両方をそろえる。

- □ 訪問介護の勤務時間の書き方: 「00:00〜23:55」（recruit-courage.dc.html:274）／「シフト制（時間応相談）」（homon/index.html:976）／「実働8時間」（kyujin.dc.html:152）
- □ サービス提供責任者になる時期: 「入社4年目で年収500万」（recruit-courage.dc.html:310）／「入社1年半〜2年でサ責」（homon/index.html:728）
- □ スタッフの年代: 「20〜60代」（saiyo.dc.html:194）／「10代〜70代」（saiyo.dc.html:137）
- □ 社会保険: 「社会保険完備」（saiyo.dc.html:269）／放デイのパートは「希望者応相談」（recruit-march-part.dc.html:274）
- □ 資格手当の額: 「1,000〜20,000円」（homon/index.html:917）／資格別 月1,000〜5,000円（recruit-courage.dc.html:332）
