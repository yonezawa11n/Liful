# 媒体戦略

最終更新: 2026-10-21

## 1. 基本方針
- 採用係長を中心に、**無料で載せられる経路をまず確実に**し、有料広告は応募の少ない求人に絞って社長の予算承認後に使う。
- **掲載を確認できていない媒体を「連携済み」として扱わない。** 確認は必ず求職者側の画面（ログアウト状態・シークレットウィンドウ）で行う。
- 応募数だけでなく、媒体ごとの**面接数・入社数・採用単価**で評価する（`python3 -m recruit report` の「媒体別の成果」）。

## 2. 媒体ごとの状況と確認方法

| 媒体 | 状況（10/21） | 確認方法 | 確認後の次の一手 |
|---|---|---|---|
| 採用係長 | 利用中（10枠） | 社長の管理画面: 契約プラン・公開中の求人・連携先の一覧・応募者CSV出力の有無 | 連携先と CSV 出力の有無を media.json に記録 |
| Indeed | **未確認** | シークレットウィンドウで jp.indeed.com を「職種名＋市名」（例: 訪問介護 町田市）と「ニューバリー」で検索 | 出ない場合: Indeed の無料直接投稿を社長に提案（重複しないよう採用係長側との二重掲載に注意） |
| 求人ボックス | 未確認 | 求人ボックスで会社名検索 | 同上 |
| スタンバイ | 未確認 | スタンバイで会社名検索 | 同上 |
| Google しごと検索 | 未確認 | Google で「訪問介護 求人 町田市」を検索し、求人の枠に出るか | 出ない場合: 採用係長の求人ページが対応しているか社長経由で問い合わせ |
| ハローワーク | 未確認 | ハローワークインターネットサービスで事業所名検索 | 出していなければ申込を提案（無料・福祉職の応募者が多い） |
| 公式LINE | 利用中 | — | 応募・相談の受け皿。応募経路に「公式LINE」と記録 |
| 自社採用サイト | 利用中 | エントリーフォームの送信処理を要確認（RISKS.md R-09） | 修正まで LINE を主導線に |
| Instagram | 利用中（@newvalley_recruit） | — | SNS採用計画で投稿。プロフィールのリンク先を求人・LINE に |
| TikTok | 未開設 | — | 開設は社長判断。開設するなら Instagram リールの転用から |
| 紹介 | 利用中 | 紹介制度（紹介手当など）の有無を確認 | 制度があれば職員向けに案内 |

**Indeed について調べてわかったこと（公開情報）**
- Indeed のクローリング（Web 上の求人を自動で集める仕組み）による掲載は、2025年6月末で終了したと複数の記事が報じている。
- 現在は「Indeed に直接投稿」か「Indeed と正式に連携したサービス経由」のどちらか。
- 採用係長が現在 Indeed の正式連携先かどうかは、公開情報では確認しきれなかった → **社長の管理画面と求職者画面で確認する**。

## 3. 記録する項目（週1回）
`python3 -m recruit media` で、媒体×求人ごとに **表示数・クリック数・広告費** を記録。
応募数・面接数・採用数・採用単価は応募者データから自動で計算する。

| 項目 | 出どころ |
|---|---|
| 媒体名・掲載求人・掲載開始/終了日 | media.json、job_status.csv（publish） |
| 無料・有料の区分、広告費 | 社長の承認内容・請求 |
| 表示数・クリック数 | 採用係長・Indeed の管理画面（社長） |
| 応募数・面接数・採用数・採用単価 | 自動集計 |
| 次の改善策 | `diagnose` と週次レポート |

## 4. 有料広告の判断基準（案・社長承認が必要）
- 公開から2週間たっても表示数が少ない求人、または入社確定の不足が大きい事業の求人に限定する。
- 開始前に「求人・期間・上限金額・やめる条件（例: 2週間で応募0件なら停止）」を決めて社長が承認する。
- 採用単価（広告費 ÷ 入社確定数）で効果を判断する。
