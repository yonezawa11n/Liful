# 応募者対応テンプレート（送信は人が行う）

このツールは応募者に連絡しません。下の文面を元に、採用担当が内容を確認して送ります。
面接日時・内定・不採用は、社長・事業責任者が決めた内容だけを送ります。

## 1. 初回連絡（応募から24時間以内）
```
〇〇様

このたびは株式会社NewValley（ニューバリー）の【求人名】にご応募いただき、ありがとうございます。
採用担当の【名前】です。

一度、面談（【所要時間】）でお仕事の内容や働き方をご説明できればと思います。
下記の候補からご都合のよい日時をお知らせください。

・【候補日1】
・【候補日2】
・【候補日3】

場所：【事務所の住所】（履歴書をお持ちください）
ご都合が合わない場合は、ご希望の日時をお知らせください。

株式会社NewValley 採用担当【名前】
```
→ 送ったら `status <ID> 面接日程調整中`

## 2. 面接日時の確定
```
〇〇様
【日時】で承りました。当日は【場所】までお越しください。
駐車場：【有無】／持ち物：履歴書
ご不明点はこのメッセージ（または公式LINE）でお気軽にご連絡ください。
```
→ `status <ID> 面接予定 --date <面接日>`

## 3. 面接前日のリマインド
```
〇〇様　明日【時刻】の面談、お待ちしております。ご都合が悪くなった場合はご連絡ください。
```

## 4. 内定（社長・事業責任者の決定後）
```
〇〇様
先日は面談のお時間をいただき、ありがとうございました。
ぜひ一緒に働いていただきたく、内定のご連絡をいたします。
労働条件（給与・勤務時間・休日など）は労働条件通知書でご説明します。
【説明の日時・方法】
ご不明な点は、どんな小さなことでもお聞かせください。
```
→ `status <ID> 内定`。条件の説明は書面で行い、求人原稿との違いがないか確認する。

## 5. 不採用（決定後）
```
〇〇様
このたびはご応募いただき、ありがとうございました。
慎重に検討しました結果、今回はご希望に沿いかねる結果となりました。
〇〇様の今後のご活躍をお祈りしております。
```
→ `status <ID> 不採用`（理由は申し送りに書かない。必要なら面接評価は別の決められた場所に）

## 6. 年末年始の応募受付案内（12/21〜1/3）
```
ご応募ありがとうございます。【休業期間】は休業のため、【日付】以降に順次ご連絡いたします。
```
